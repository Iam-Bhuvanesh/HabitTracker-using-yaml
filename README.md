## 🚀 How to Use

### Add a New Task
[Click here to add a new task](https://github.com/Iam-Bhuvanesh/HabitTracker-using-yaml/issues/new) by using the task name as the issue title.

### Mark Task as Done
Click "Tick It" next to any habit, or open an issue with the title `DONE TaskName`.

### Remove a Task
Open an issue with the title `REMOVE TaskName`.

### Reset/Refresh Tasks
Open an issue with the title `REFRESH` to manually reset tasks.
