## 🚀 How to Use

### Add a New Task
[Click here to add a new task](https://github.com/Iam-Bhuvanesh/HabitTracker-using-yaml/issues/new?title=New%20Task)

### Mark Task as Done
Click "Tick It" or create issue: `DONE TaskName`

### Remove a Task
Create issue: `REMOVE TaskName`

### Set Category
Create issue: `CATEGORY TaskName | Learning`

### Set Priority
Create issue: `PRIORITY TaskName | High`

### Set Frequency
Create issue: `FREQUENCY TaskName | daily`
